# Variant Lab

`/` and `/variant-lab/` both render the same homepage content through
`_includes/variant_home.html`. Update news, papers, links, and copy there once;
every visual theme uses the same markup.

It includes the default dark layout plus five alternate visual directions:

1. `default dark` - the baseline retro homepage in dark mode.
2. `default light` - the original warm retro homepage.
3. `solarized` - Solarized Dark styling with a blinking caret detail and blocky cursors.
4. `serious academic` - restrained paper-like styling with citation-ish details and a pen cursor.
5. `2010s blogspot` - early-blog textures, paper tones, framed photo treatment, and pencil cursors.
6. `peak 2000s` - louder retro energy with animated cursors, hover toys, noisy colors, and a best-viewed badge.

The old `retro-preview/` entry point redirects to `/variant-lab/`.
