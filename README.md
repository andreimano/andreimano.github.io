# andreimano.github.io

Static personal website for Andrei Manolache.

The current `master` branch is intentionally lightweight: plain HTML, CSS, and
JavaScript with no Jekyll build step.

## Structure

- `index.html` - main homepage.
- `variant-lab/` - same homepage with the theme switcher preserved as a direct URL.
- `retro-preview/` - legacy preview redirect.
- `assets/img/prof_pic.jpg` - profile photo.
- `assets/pdf/Manolache_Andrei_CV2025.pdf` - current CV.
- `msc_thesis_manolache.pdf` - master's thesis PDF.

Archived branches:

- `old-al-folio` - the original al-folio site before the redesign.
- `full-site-before-static-cleanup` - the intermediate Jekyll tree with the new variant homepage and old files still present.
